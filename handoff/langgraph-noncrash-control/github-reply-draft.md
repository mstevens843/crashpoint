Separate from the pre-first-checkpoint crash/recovery result above (unchanged - see
`results/10-langgraph-admission-ledger.md`), here is the non-crash control:
`admission_id -> thread_id -> execution result -> external effect reference -> independently
rereadable state hash -> receipt`.

One ordinary, non-crashed LangGraph 1.2.11 execution (`langgraph-checkpoint-sqlite` 3.1.1). A
caller-owned admission record - identity and original input, committed to SQLite - is durable before
`app.invoke()` is ever called; the UTC timestamp is generated by the harness right before that commit
and recorded in the receipt, not itself part of the durable admission row. The worker reads its input
back from that record, not from its own arguments. `durability="sync"`, one invoke, no crash injected.
The node makes one harmless call to an out-of-process ledger.

After the worker exits, a freshly spawned, separate observer process - not the worker, not
`ledger.dump()` - opens the ledger's on-disk store with its own file handle, hashes the raw bytes,
verifies the record chain, and derives the effect count and reference for this run's identity
directly from what it read. It archives an exact copy of those bytes and confirms the copy's hash
agrees with the original before the ephemeral daemon/socket directory is cleaned up.

Result of the one recorded run:

- Admission: accepted before invoke, event sequence `accepted -> completed`.
- Worker: exit 0, returned `{"done": true}`.
- Checkpoints for this thread: 3.
- Observer: `OBSERVED`, hash chain valid, archived bytes match the original readback.
- Effect count for this run's identity: 1.
- Classification: `EXACTLY_ONCE`.

An offline verifier (`crashpoint.harness.langgraph_control_verify`) recomputes the outer receipt
hash and declared artifact hashes, independently re-parses the ledger readback, and independently
re-queries the retained checkpoint/admission SQLite files. Runtime metadata, including versions,
timestamps, process IDs, and exit status, remains recorded metadata checked for consistency, not
independently authenticated execution evidence. The verifier does not import or launch LangGraph,
rejects any declared path that is absolute or that
resolves (including through a symlink) outside the bundle, and verifies identically after the bundle
is copied to another local directory (every path it opens is bundle-relative; this was verified by
relocating the bundle locally, not by testing on a separate machine). PASS, exit 0.

This is a positive control and an evidence-portability test - not a LangGraph fix, not a crash or
recovery measurement, not a global exactly-once guarantee, provider idempotency, admission/dispatch
fencing, or SABLE certification. It is one recorded run (n=1): no statistical rate is claimed. Full
writeup: `results/12-langgraph-noncrash-control.md`.
